# 🔌 Fundamentos de Hardware (FH)

En esta sección se agrupan los trabajos y prácticas relacionados con la arquitectura física de los sistemas informáticos, el análisis de sus componentes esenciales y las estrategias de respaldo de información.

---

## 🛠️ Trabajos Incluidos

### 🧠 Procesador
* **Descripción:** Trabajo enfocado en el estudio del procesador (CPU), analizando sus características técnicas, funcionamiento, arquitectura y rendimiento.

### 🟩 Placa Base
* **Descripción:** Análisis detallado de la placa base, sus componentes integrados, chipsets, zócalos y las conexiones necesarias para la interconexión de todo el hardware.

### 💾 Backup
* **Descripción:** Prácticas dedicadas a la planificación y ejecución de copias de seguridad para asegurar la protección, disponibilidad y recuperación de los datos del sistema.
