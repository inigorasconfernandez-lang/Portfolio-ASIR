# 📁 Portfolio Personal - ASIR (Administración de Sistemas Informáticos en Red)

¡Bienvenido/a a mi portfolio personal! En este repositorio he recopilado los trabajos y prácticas más importantes realizados a lo largo del ciclo formativo de ASIR. El objetivo de este espacio es mostrar de forma organizada las competencias adquiridas en administración de sistemas, redes, bases de datos, desarrollo y hardware.

---

## 📚 Organización del Portfolio

El repositorio está estructurado por carpetas, correspondiendo cada una a una asignatura del curso. Dentro de cada carpeta encontrarás la documentación, memorias y código de las prácticas clave:

* **[🌐 LMSGI](./LMSGI):** Proyecto integrador de la página web de una empresa de gestión de redes sociales (Agencia de Social Media), desarrollado y mejorado por fases.
* **[📊 GBD](./GBD):** Trabajos de diseño de bases de datos con Visio, prácticas de implementación/consultas y aplicación de reglas de normalización.
* **[🖥️ ISO](./ISO):** Prácticas de gestión de almacenamiento avanzado (LVM, RAID y administración multidiscos).
* **[🔌 PAR](./PAR):** Proyectos de infraestructura física (Cableado Estructurado), servicios de red (SSMTP) y configuración de Routers.
* **[💻 PPY](./PPY):** Desarrollos de código y resolución de scripts de automatización (Prácticas de código, Actividad 32 y Actividad 33).
* **[🧠 FH](./FH):** Trabajos de arquitectura de hardware (Procesador y Placa Base) y planificación de estrategias de Backup.

---

## 🛠️ Tecnologías y Entornos Utilizados

A lo largo del curso, he trabajado y adquirido experiencia con las siguientes herramientas:
* **Sistemas Operativos:** Linux (Debian/Ubuntu Server) y Windows Server.
* **Redes y Hardware:** Configuración de routing, cableado y análisis de componentes de hardware.
* **Bases de Datos y Datos:** Lenguaje SQL, Microsoft Visio, formatos XML y JSON.
* **Desarrollo y Diseño Web:** HTML5, CSS3 y lenguajes de Scripting para automatización.
* **Almacenamiento:** Gestión de RAID, LVM y políticas de copias de seguridad (Backup).
