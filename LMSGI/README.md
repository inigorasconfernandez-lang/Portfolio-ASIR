# 🌐 Lenguajes de Marcas y Sistemas de Gestión de Información (LMSGI)

En esta sección se encuentra el desarrollo de mi proyecto integrador de la asignatura. Consiste en la creación de una página web para una empresa que se encarga de gestionar las redes sociales de distintas empresas o negocios (Agencia de Social Media).

El proyecto está dividido en cuatro fases consecutivas. En cada una de ellas, he ido mejorando y evolucionando el sitio web con todo lo que el profesor nos ha ido enseñando a lo largo del curso.

---

## 🚀 Fases del Proyecto

### 📁 Fase 1
* **Descripción:** Primera versión de la página web de la empresa de gestión de redes sociales, enfocada en crear la estructura inicial y el contenido de la web.

### 🎨 Fase 2
* **Descripción:** Mejora del proyecto aplicando hojas de estilo para darle un diseño visual moderno, profesional y adaptado al negocio.

### 📄 Fase 3
* **Descripción:** Evolución del proyecto introduciendo el almacenamiento y la organización de los datos de la empresa en formatos estructurados.

### 🛡️ Fase 4
* **Descripción:** Última fase del proyecto donde se añadieron las reglas de validación necesarias para asegurar el correcto control de los datos del negocio.
