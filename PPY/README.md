# 💻 Programación y Lenguajes de Script (PPY)

En esta sección se recopilan los desarrollos de código y scripts realizados durante el curso, orientados a resolver problemas de lógica de programación y a automatizar tareas del sistema.

---

## 🛠️ Trabajos Incluidos

### 📜 Prácticas de Código
* **Descripción:** Conjunto de programas y ejercicios enfocados en el aprendizaje de la lógica de programación, estructuras de control, funciones y manejo de datos.

### 📁 Práctica 32
* **Descripción:** Desarrollo de un script específico diseñado para cumplir con los requisitos lógicos y de automatización solicitados en la actividad número 32.

### 📁 Práctica 33
* **Descripción:** Implementación y desarrollo de la solución en código correspondiente a la actividad práctica número 33 del curso la cual se basa en conseguir el correcto funcionamiento de una calculadora.
