# 📊 Gestión de Bases de Datos (GBD)

En esta sección se recopilan los trabajos prácticos realizados en la asignatura, enfocados en el diseño conceptual, lógico y la posterior implementación y explotación de bases de datos relacionales.

---

## 🛠️ Trabajos Incluidos

### 📐 Modelos y Diseños en Visio
* **Descripción:** Diagramas conceptuales y esquemas Entidad-Relación realizados con Microsoft Visio para planificar la estructura y relaciones de los datos antes de su creación.

### 💾 Prácticas de Bases de Datos
* **Descripción:** Implementación real de los diseños sobre el sistema gestor de bases de datos, incluyendo la creación de tablas, la definición de restricciones y la realización de consultas para extraer y gestionar la información.

### 🔄 Normalización
* **Descripción:** Aplicación de las reglas de normalización (Formas Normales) a los diseños de las bases de datos para eliminar la redundancia de datos, evitar anomalías y garantizar la integridad de la información.
